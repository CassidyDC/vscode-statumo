# Agent Instructions

## Commits

- After completing each task or feature, create a Git commit for the changes made for that task.
- Keep each commit limited to files and changes that belong to the completed task. Do not include unrelated or pre-existing changes.
- Follow the established commit-message style: use a concise imperative subject starting with a capitalized verb (for example, `Add demo video`). Do not use Conventional Commit prefixes such as `feat:`, `fix:`, or `docs:`.
- Do not add attribution to anything written to Git or GitHub: commit messages, tags, pull
  request titles and descriptions, issues, comments or release notes. That includes
  `Co-Authored-By` lines and any "Generated with Claude", "Generated with Claude Code" or
  similar text, links or emoji.

## Repository instructions

- Add a concise entry to `CHANGELOG.md` and/or update `README.md` when the task changes project behavior, capabilities, setup, or usage in a way that users should know about. Also add a changelog entry when the task adds or significantly changes documentation, including generated references, guides and reviews.
